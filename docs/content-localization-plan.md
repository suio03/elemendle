## 1. 已确定的策略

- 当前只维护英文 guide，所有语言的页脚都显示入口，并标注 English。
- 翻译暂缓；未来若恢复，根据实际需求选择语言，不预设哪个语言流量更大。
- 每个语言必须完成整篇内容和对应页面文案后再发布。
- 未翻译的语言不生成对应可索引文章，不自动显示英文正文作为本地化内容。
- 属性题通常可翻译；文字游戏需要当地语言重写，并重新检查答案。

这是本次内容页面明确采用的分批策略。旧留存路线图中“所有新增文案同步全部语言”的描述不作为本次文章全语言首发要求。既有游戏界面的翻译规范不受影响；若修改共享界面，仍保证实际展示给用户的标签完整。

## 2. 如何选择下一种语言

1. 若有 Search Console，按页面、查询和国家查看实际曝光与点击；国家不直接等于语言。
2. 若现有网站统计提供语言或 locale 路径数据，查看已有用户的语言分布。
3. 同时考虑能否对该语言进行可靠的化学术语和表达审核。
4. 记录数据来源、统计起止日期、语言或地区维度，以及选择理由。
5. 数据不足时明确标记为试点选择；不要写成“高搜索量市场”。

可用此表记录：

| 候选语言 | 数据来源与日期范围 | 观察结果 | 审核能力 | 决定与理由 |
| --- | --- | --- | --- | --- |
| 暂不选择 | 尚未获取 | 未知 | 未安排译文审核 | deferred：当前仅提供英文 |

没有数据不阻塞英文内容准备，也不意味着自动授权全语言翻译。

## 3. 翻译范围

每篇文章逐项覆盖：

- 页面标题、简介、使用说明、目录和难度标签。
- 所有题目、元素名称、答案和解析。
- 解题方法、参考资料说明、审核日期标签。
- 按钮、链接文案和可访问性标签。
- SEO title、description、分享文案及需要本地化的图片替代文本。

元素符号保持科学规范写法。名称采用目标语言常用的规范名称，不机械音译英文。

不要把内部事实核查笔记、候选筛选记录或工作流说明直接放进产品正文；面向读者展示简洁参考资料即可。

## 4. 哪些内容需要重写

| 线索类型 | 处理方式 |
| --- | --- |
| 族、周期、原子序数等属性 | 保持事实与答案，准确翻译术语 |
| 物态与用途 | 保持条件与限定，检查目标语言是否产生歧义 |
| 名称来源 | 核对当地名称与词源关系，必要时调整讲解 |
| 首字母、字母数量 | 不能沿用英文结论；按目标语言重写或换题 |
| 谐音、押韵、双关 | 重新创作并审核；不强行逐字翻译 |

首版优先避免后三类作为关键线索。即使答案未改变，翻译后仍需要再做一次唯一性检查。

## 5. 路由与 SEO 约定

项目当前内部 locale 为：`en`、`de`、`jp`、`fr`、`es`、`it`、`pt`、`ru`、`ko`、`ch`、`ar`、`hi`、`nl`。英文采用无前缀路径。

- 英文文章：`/learn/periodic-table-riddles`。
- 其他语言沿用现有 locale 前缀，不在内容项目中随意改全站路由。
- 单独记录每篇文章的已发布语言；不能直接把全站 locale 列表当作文章已发布语言列表。
- 英文文章不提供不存在的译文切换；各语言站点均显示相同英文入口，链接使用英文规范 URL，并标注 English 与 `hreflang="en"`。
- 用户访问带非英文 locale 的 guide 路径时，临时重定向（307）至英文规范 URL，并保留查询参数；不再返回 404。英文 URL 始终渲染英文，不被 Cookie 或浏览器语言重定向。
- sitemap 只列实际发布且可索引的文章 URL。
- 每种译文使用自己的 canonical；hreflang 只列真实发布的版本并保持互相对应。
- 若使用 `x-default`，指向作为默认版本的英文文章。
- 内部 locale 路径名与标准语言代码分开处理。例如内部 `jp` 在 hreflang 应映射为 `ja`，`ch` 的简体中文内容应使用适合内容的 `zh-Hans` 等有效标签；核对现有语言声明后实施，不能原样输出非标准内部键。
- 不要把所有译文 canonical 都指向英文，也不要为不存在的译文生成 alternates。

首篇页面已完成共享导航和语言路由验证：所有入口指向英文，非英文前缀跳转英文。未来新增译文时重新验证对应行为。

## 7. 源文修订后的维护

- 英文修改题目、答案或解释时，以题目 ID 标记受影响译文。
- 科学事实或答案错误优先同步修正；无法及时修正的译文暂缓发布或撤下受影响内容，不继续标记为已审核。
- 仅英文措辞变化时判断是否影响译文，不必机械重译整篇。
- 新题可以先在英文发布，但各语言页面若声明题目数量，必须与本页实际内容一致。
